# jetbrains-idea-workflow

面向 Codex 的 JetBrains IDEA 开发工作流技能。它将源码理解、方案设计、功能实现、问题修复、检查验证和交付整理为一套可复用的工程流程，适用于依赖 IDEA 项目语义、符号、Inspection、运行配置或数据库能力的任务。

## 能力范围

- 通过 IDEA MCP 状态门禁访问项目源码、符号、依赖、工作区和运行能力。
- 支持源码定位、调用链分析、需求设计、功能开发、Bug 修复和重构。
- 覆盖前端、Vue、数据库与 SQL、系统功能设计等专项工作流。
- 根据命令实际影响范围约束编译、构建、测试、Inspection、启动和其他验证操作。
- 对数据库写入、依赖变更、环境配置、发布以及 Git 提交和推送等高风险操作执行独立确认。

## 安装

将本仓库目录安装到 Codex 的 skills 目录，例如：

```text
$CODEX_HOME/skills/jetbrains-idea-workflow
```

安装后，在 Codex 中打开需要处理的 JetBrains IDEA 项目，并提出开发、排查、设计或验证需求即可触发该技能。

## 目录结构

```text
SKILL.md                    技能入口与路由规则
references/                 核心工作流及专项工作流说明
agents/openai.yaml          Agent 元数据
```

## 工作流说明

技能会根据任务类型选择相应流程：

1. 读取项目约束、任务上下文和必要的参考规则。
2. 在需要 IDEA 项目能力时完成 MCP 状态门禁。
3. 基于源码、配置和数据库只读信息确认事实与影响。
4. 在明确范围内进行最小变更，并执行适用的文件级检查。
5. 汇总实际验证范围、未验证项和潜在影响后交付结果。
