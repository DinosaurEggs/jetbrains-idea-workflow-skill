# IDEA MCP 运行工具契约

本文件列出运行配置和运行任务子工具的允许清单、已确认参数和组合。运行授权、持续进程、验证范围和结果判定由 `非文件级执行与验证.md`
负责。

## 工具契约

| 子工具                      | 用途                                   | 必填参数                                                                                                                                                                                                                            | 可选参数与条件                                                                                                                                                                                                                                                                                                                                                                                                         |
|-----------------------------|----------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `get_run_configurations`    | 列出项目运行配置或指定文件的可运行位置 | 无                                                                                                                                                                                                                                  | `filePath:string`：项目相对路径；省略时返回项目运行配置，传入时只返回该文件中 IDEA 识别的可运行位置                                                                                                                                                                                                                                                                                                                    |
| `execute_run_configuration` | 按配置名或代码位置启动运行任务         | 以下两种模式二选一且互斥：① `configurationName:string`，精确复用 `get_run_configurations` 返回的配置名；② 同时传入 `filePath:string` 与 `line:number`，其中路径为项目相对路径，行号从 1 开始并精确复用该文件返回的 `runPoints.line` | `envs:object<string,string>`：仅当所选配置返回 `supportsDynamicLaunchOverrides=true` 时可传，值与既有环境变量合并；`programArguments:string`、`workingDirectory:string`：同样仅在该标志为 `true` 时可传，省略、`null` 或空字符串表示保留既有值，仅空白字符串表示清空本次启动值；`waitForExit:boolean`：`true` 等待进程终止，`false` 只等待启动；`timeout:number`：毫秒，仅在 `waitForExit=true` 时生效，`false` 时忽略 |

## 选择与使用

- 启动任务前使用 `get_run_configurations` 确认已有配置、可运行位置、动态覆盖支持和工作目录。
- 优先使用已确认的 `configurationName`。按代码位置启动时，`filePath` 和 `line` 必须来自当前工具返回的可运行位置，`line` 从
  1 开始。
- `configurationName` 模式与 `filePath`、`line` 模式不得混用。
- 只有所选配置明确返回 `supportsDynamicLaunchOverrides=true`，且授权范围确实需要时，才传入临时 `envs`、`programArguments` 或
  `workingDirectory`。
- `timeout` 使用毫秒，只在 `waitForExit=true` 时生效；`waitForExit=false` 时工具忽略该参数。
- 只有已经存在可复用的会话、任务标识或 PID，并且同时存在能够确认状态和终止该任务的机制时，才设置 `waitForExit=false`
  ；仅有日志或输出路径不满足该条件。否则使用 `waitForExit=true`。
- `waitForExit=true` 超时后，进程状态和退出码可能未知。复用返回的会话、任务、PID 或日志补齐状态；没有可用标识时，将结果标记为状态未知，不直接重跑。
- 临时覆盖不得写回持久化运行配置。修改持久化配置按 `高风险确认.md` 独立确认。
- 外层调用成功只表示统一入口已响应；必须继续检查实际任务状态、输出、超时和退出信息。
