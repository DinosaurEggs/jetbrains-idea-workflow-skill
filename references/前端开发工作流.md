# 前端开发工作流

## 适用边界

本文件规定所有前端任务共用的上下文、前后端契约、状态、联调、响应式和可访问性基础。

Vue 专项由 `Vue开发工作流.md` 负责；视觉质量由 `前端界面设计质量.md` 负责；文件级闭环由 `编辑格式化与文件级检查.md`
负责；非文件级执行由 `非文件级执行与验证.md` 负责。加载条件由 `SKILL.md` 统一决定。

## 定位与上下文

根据任务定位路由、菜单、页面标题、组件、API 方法、HTTP method 与 URL、store、状态逻辑、权限标识和用户可见文案。

按实际影响读取：

- 页面、表单、弹窗、详情及相关公共组件；
- API 封装、请求与响应类型、状态管理和复用逻辑；
- 路由、菜单、权限配置和设计系统入口；
- 对应后端 Controller、DTO/VO、返回结构及异常契约；
- 相关测试和项目中的同类实现。

搜索或符号结果只用于定位；结论和编辑必须基于当前源码、配置与接口契约。

## 契约、状态与联调

修改前查明：

- 查询、表格、表单和详情字段的名称、类型、必填、默认值、枚举、字典及日期时间格式；
- 请求的 HTTP method、URL、参数来源、分页、排序和序列化方式；
- 后端请求 DTO、响应 VO、返回包装、错误码、异常结构和校验顺序；
- loading、empty、error、disabled、readonly、selected 和权限受限状态中实际适用的状态及其切换；
- 菜单、页面、按钮和数据权限是否一致；
- 公共组件、公共类型、store、缓存状态、路由生命周期、并发请求和其他调用页面的影响。

以前端 HTTP method 和 URL 串联 API 封装、请求响应类型、后端入口和页面行为。不得只修改一端后假设另一端兼容；存在兼容要求时，查明相关调用方和旧数据处理方式。

必要查证后仍无法唯一确定，且不同选择会改变业务行为、接口契约、权限或结果时，按 `SKILL.md` 处理待定决策。

## 响应式与可访问性

- 在项目或用户要求支持的目标视口中，保证文本、控件、浮层、表格和动态内容不溢出、不遮挡，核心操作保持可用。
- 使用与项目一致的容器、布局、断点和尺寸约束；为长名称、国际化文本、异常数值和动态内容规定换行、截断或弹性布局。
- 按项目和用户要求支持目标输入方式。交互控件保留正确语义和可访问名称；核心操作不得只依赖悬停、颜色、图标或动画。
- 焦点必须可见且顺序与内容逻辑一致；表单错误必须能够被定位和理解。
- 非文本内容提供替代信息；减少动画后仍保留完整功能和状态反馈。

领域风格、排版、色彩、控件选择、动效和素材要求由 `前端界面设计质量.md` 负责，不在本文件重复。

## 修改与验证边界

优先复用项目已有组件、类型、设计系统和交互模式，不把局部任务扩大为公共改造或全站重设计。

修改完成后按 `编辑格式化与文件级检查.md` 完成文件级闭环；非文件级类型检查、构建、测试、运行、浏览器和截图按 `非文件级执行与验证.md`
处理。
