# 前端界面设计质量

本文件只在 `SKILL.md` 指定的设计类前端任务中追加应用。它提高视觉与交互决策质量，不授权扩大需求、替换既有设计系统、下载外部资源、增加依赖或跳过设计先行与执行门禁。通用契约、状态和联调要求见 [frontend-workflow.md](frontend-workflow.md)。

## 决策优先级

按以下顺序解决设计冲突：

1. 用户明确要求。
2. 项目 `AGENTS.md`、代表性页面、组件库和设计系统。
3. 产品领域、目标用户和高频任务。
4. 本文件的质量原则。
5. 通用审美偏好。

既有产品先阅读代表性页面、全局样式、主题令牌、公共组件、图标和响应式规则，再延续其视觉语言。除非用户明确要求重设计，不得把局部任务扩成全站改版。

## 编码前确定方向

开始实现前明确界面目的、目标用户、核心流程、信息优先级、主要设备、失败成本、设计系统、性能和浏览器约束，并选择一项有领域或品牌依据的识别点。用排版、色彩、密度、空间和交互一致地表达方向；设计强度服务于任务，不以夸张程度衡量质量。

## 领域匹配

- 企业后台、CRM、ERP 和其他操作型系统保持安静、紧凑和稳定，优先扫描、比较、录入及重复操作效率，不套用营销页构图。
- 官网、品牌页、作品集和内容型页面可以增强编辑感、叙事与品牌识别，但首屏应直接呈现真实主体或核心价值。
- 游戏和娱乐体验可以更具表现力，但核心玩法、操作可见性和反馈优先于装饰。
- 同一产品延续既有心智模型；新增差异必须有领域、品牌或任务依据。

## 排版与信息层级

- 优先使用项目已有字体、字号、字重和行高体系；未经确认不得下载字体或新增字体依赖。
- 用标题、正文、标签、数据和辅助信息建立稳定层级；紧凑面板、卡片、侧栏和工具区不得使用首屏级大字。
- 保持正文可读宽度和足够行高，不用视口宽度直接缩放字号，不用负字距压缩文本。
- 为长名称、国际化文本、数字和异常值设置换行、截断、最小宽度或弹性布局，避免内容破坏信息层级。

## 色彩与设计令牌

- 复用项目 CSS 变量、主题令牌和语义色；新增局部值前先判断能否归入现有令牌。
- 建立清晰的背景、表面、文字、边框、主操作、状态和焦点层级，强调色只用于真正需要注意的内容。
- 避免缺少领域依据的单色铺满、陈旧渐变套路、平均分配视觉权重和只靠阴影区分结构。
- 渐变、纹理、噪点、透明层和强阴影只在设计方向确有需要时使用，不作为默认装饰。

## 布局、密度与响应式

- 根据任务选择受控密度或留白，不为形式感牺牲信息关系和操作路径。
- 用稳定的容器、网格、断点和尺寸约束组织内容，使桌面与移动布局都体现清晰的优先级，而不是简单缩放。
- 操作型界面优先清晰导航、稳定工具区、可比较数据和短操作路径；不要把页面区段全部做成悬浮卡片，也不要嵌套装饰卡片。
- 移动布局应重新安排导航、主要操作、弹层和表格替代视图，保证目标设备上的信息与操作可用。

## 控件与交互

- 使用符合语义的控件：熟悉工具使用图标按钮，颜色使用色块，模式使用分段控件，二元设置使用开关或复选框，数值使用输入、步进器或滑杆，视图切换使用标签页。
- 项目已有图标库时优先复用；存在通用图标时不要手绘替代。仅图标按钮必须有可访问名称，不熟悉的图标补充 tooltip。
- 表单提供清晰标签、校验、错误恢复和提交反馈；危险或不可逆操作与普通操作保持明确层级。
- 实现真实可用的交互，不用静态占位、假按钮或无反馈装饰替代功能。
- 不添加宣传式文字解释页面功能、视觉特点或使用方式，除非它本身是业务内容或必要帮助。

## 动效与反馈

- 动效用于解释变化、层级、空间关系和操作结果，不以数量制造精致感。
- 优先使用项目已有方案；简单交互优先 CSS，未经确认不得新增动画库。
- 控制持续时间、节奏和同时运动的元素数量，避免高频操作反复播放大幅动画。
- 尊重 `prefers-reduced-motion`，关闭动画后仍应保留功能和信息。

## 视觉素材与装饰边界

- 需要图片或媒体时优先使用项目已有或用户提供的真实素材，并让素材展示实际产品、地点、对象、状态或玩法。
- 未经确认不得下载外部图片、字体、图标包或生成素材；素材来源、许可、体积和加载失败处理必须可控。
- 装饰元素必须支持品牌、领域或信息层级；自定义光标、复杂背景、强烈叠层和实验性布局不得成为无依据的默认选择。
- 品牌或对象导向页面应让主体在首屏形成清晰信号；操作型页面优先让核心任务和当前状态可见。

## 可访问性质量

- 使用语义化结构、正确标签和可预测的内容顺序，使辅助技术能够理解层级、关系和操作结果。
- 图标和非文本内容提供替代信息，表单错误可被定位和理解，缩放和长文本不破坏内容顺序。
- 视觉差异不能损害键盘路径、焦点可见性、对比度或减少动态效果设置。
