# IDEA MCP 状态门禁

## 统一入口与结果

当前 IDEA MCP 仅通过 `mcp__idea__execute_tool` 暴露统一入口，具体 IDEA 子工具写入 `command` 动态调用；不得假设子工具还以独立 MCP tool 注册。统一入口已注册只证明路由存在，不证明任务所需子工具可用。

门禁 bootstrap 调用传入从允许上下文查明的候选项目绝对根路径；门禁通过后，每次调用都传入已确认的项目根。不得省略 `projectPath`、用终端工作目录代替项目身份，或把成功传参本身当作项目匹配证据。

每次调用先检查统一入口，再检查子工具结果。外层 `isError=false` 只表示路由返回响应，不表示子工具成功。外层 `isError=true`、子工具 `errorMessage` 非空、`timedOut=true`、明确的 timeout、`isSuccess=false`、`command_exit_code` 非 0，或补丁未全部 applied，均表示失败或未完成；必须判读 `problems`，`more`、`notAnalyzedReason`、截断、缺少退出状态或部分批次表示结果不完整。工具调用成功不等于检查通过，例如 warning 可与调用成功同时存在。

## 触发与 bootstrap

任务需要当前 IDEA 项目的源码、符号、依赖、VCS、编辑、inspection、运行配置、构建、数据库或调试能力时，首次访问项目内容前必须完成本门禁。skill 维护、普通文档和其他不依赖项目语义的元任务除外；该例外不是异常后的降级路径。

门禁前只允许：

- 直接应用当前上下文已提供的 `AGENTS.md`。
- 在项目根或工具规则未知时，最小查明候选项目绝对路径、当前工具目录和直接适用的 `AGENTS.md`。

不得在 bootstrap 阶段读取业务源码、配置、测试、依赖或数据库，执行项目命令或编辑项目文件。

## 门禁检查

用当前工具目录中的只读项目身份能力确认：

1. IDEA MCP 统一入口已经注册且连接正常，完成任务所需的子工具能力可以通过该入口调用。
2. IDEA 当前打开项目与任务目标绝对路径一致；终端工作目录不能代替项目身份。
3. 多模块或多仓库工作区可以把目标文件映射到明确模块和 VCS 根。

统一入口可用但缺少任务必需的子工具能力，同样表示门禁不满足。子工具名称和参数以当前实际契约为准；不得虚构项目身份工具。有效查询零匹配不是门禁失败；参数错误只能依据已知事实修正，连接、传输、会话、插件或项目状态错误不得当作参数问题继续尝试。

## 异常与恢复

统一入口未注册、连接异常、IDEA 未打开目标项目、项目不匹配或必需子工具能力不可用时：

1. 停止依赖 IDEA 的阅读、定位、设计、编辑、检查、构建和验证，只保留目标项目、缺失能力、错误依据和影响。
2. 不自动重试、启动或切换 IDEA、重连或配置 MCP，也不搜索其他 IDEA 实例。
3. 不自动改用终端、文件系统、其他 MCP、IDE 或替代实现。
4. 按 [core-workflow.md](core-workflow.md) 请用户选择修复后重试、明确指定替代方式及范围，或暂停。

用户说明状态恢复后，只调用一次原必需的最小只读能力验证。替代方式必须同时明确具体方式和范围；只回复“跳过”或未指定方式不构成确认。

## 项目与能力边界

门禁通过后，用 IDEA 确认项目根、模块、仓库和目标文件归属。修改前读取相关仓库的已暂存、未暂存、未跟踪及冲突状态；对应子工具存在时可优先使用项目/VCS 能力。

- 目标文件有既存改动时以当前内容为基础最小编辑，不恢复基线；冲突使任务无法可靠继续时保留现场并询问。
- 通过统一入口选择满足目标的最窄子工具能力。Java/Kotlin 优先语义符号、源码和调用分析；Vue/TypeScript、模板和配置先用精确标识或文本定位，再读当前源码。
- 前后端契约以 HTTP method 和 URL 串联 Controller、类型、API 封装和页面；搜索只提供候选，结论以当前源码确认。
- 依赖、JDK、JAR/JRT 或反编译源码由 IDEA 直接读取；符号重命名使用语义重构，不做文本全局替换。

编辑、inspection、执行、数据库和高风险操作遵守各自 reference，本文件不重复其规则。

## CodeGraph

先服从项目 `AGENTS.md` 的优先级、触发条件和查询方式，再服从工具实际契约。项目未规定时，仅在陌生模块、跨模块流程、多符号调用或大范围影响分析中作为可选探索。

- 禁止使用自然语言。
- 用结果确定候选符号、文件、调用和影响面；关键声明、配置及测试结论由 IDEA 当前项目复核。
- 与 IDEA 冲突时以 IDEA 为准；已有结果足够时复用，不为展示方式重复查询。
- 可选 CodeGraph 不可用或无结果时停止尝试并继续 IDEA，不自行初始化或修复索引。
- 项目规则或用户将其设为必需时，不可用即暂停相关工作并按核心流程请求处理。
