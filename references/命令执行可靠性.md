# 命令执行可靠性

## 适用边界

本文件只处理终端命令、脚本、包管理器或项目包装入口、编译、构建、测试，以及高输出、失败、超时、截断或结果丢失后的可靠执行。

本文件不判断授权，也不定义验证范围。文件级检查的授权和结果按 `编辑格式化与文件级检查.md` 处理；非文件级执行按
`非文件级执行与验证.md` 处理；数据库操作按 `数据库SQL与持久化层.md` 处理。

## 执行前核对

1. 明确命令目的、实际入口和预期证据，不按命令名称猜测行为。
2. 读取项目声明的脚本、运行配置、包管理器别名或包装器定义，查明展开后的实际命令和范围。
3. 确认 Shell、工作目录、项目或模块、路径基准和目标对象；相对路径必须能从当前工作目录唯一解析。
4. 核对影响参数边界的调用层，以及工具名、参数名、必填项、类型、引号、转义、数组、布尔值、空字符串和互斥组合。
5. 查明输出位置、退出状态和完整性信号，区分已启动、失败、不完整与通过。

工具返回参数错误时，只依据当前已加载契约或错误结果明确指出的缺失项、未知项、类型和组合条件修正；不得依次试探拼写、别名或未声明参数。

## PowerShell、路径与编码

- 区分 PowerShell 命令、原生可执行文件、`.cmd` 和 `.bat` 入口，按实际调用层处理参数。
- 含空格、特殊字符或可能被重新解释的参数，按实际调用链选择引用、转义、参数数组或停止解析机制。
- 多个候选路径中存在可能不存在的路径时分别探测，不让单个无效路径使其他目标被整体误判。
- 使用精确路径和目标，不依赖无关通配符或隐式工作目录。
- 读取外部日志时根据 BOM、工具声明或实际证据确定编码，不默认所有输出都是 UTF-8。
- 非零退出码按具体命令解释；聚合命令分别分析各部分结果。

## 构建与多模块入口

执行编译、构建或测试前，还要查明：

1. 项目实际声明的入口。
2. 影响参数传递的包装层和转义方式。
3. 工作目录、构建描述文件、聚合根和目标模块归属。
4. 目标模块的上游依赖、下游影响和聚合关系。
5. 属性、筛选条件和复合值是否按目标程序要求作为单个参数传递。

历史成功命令只可作为线索。入口、工作目录、构建结构、参数含义和授权范围全部一致时，才可复用。

构建入口失败后按错误层级处理：入口无法解析时检查项目声明和环境；参数或生命周期错误时检查 Shell
解析及参数边界；模块或依赖缺失时检查聚合关系；目标测试未匹配时检查筛选条件传播；代码或测试失败时读取对应源码和结果。每次只修正确认存在的条件。

## 高输出与结果复用

可能产生大量输出时，优先选择原生命令的精简输出、结构化报告或输出文件。

工具返回会话 ID、任务 ID、进程标识或完整输出路径时，后续等待和读取同一结果，不重新启动任务。

仍可能超过输出上限时，首次执行即把 stdout、stderr 和退出状态保存到系统临时目录的唯一日志，不写入项目。后续分段读取或搜索该日志，不为筛选、统计或查看末尾重跑任务。日志和交付内容不得泄露敏感信息。

## 失败恢复

失败后保留原命令、Shell、工作目录、输入、配置、输出和错误，再按原因处理：

| 失败类型                         | 恢复方式                                                           |
|----------------------------------|--------------------------------------------------------------------|
| 工具或参数错误                   | 核对当前契约，只修正契约或错误结果明确指出的内容。                 |
| 路径或工作目录错误               | 只读确认精确路径、归属和路径基准，条件改变后再执行。               |
| 确定性代码、配置、输入或测试失败 | 分析原因；当前任务已授权修复时，修复后只复跑原验证范围。           |
| 环境或依赖缺失                   | 停止依赖该项的执行；不得自行安装、切换工具链或修改业务代码绕过。   |
| 瞬时连接或传输故障               | 仅在操作可安全重试且不会重复副作用时，执行一次最小范围重试。       |
| 批次不完整或结果丢失             | 只补做缺失文件、批次或检查。                                       |
| 超时或进程状态未知               | 按适用验证规则复用原会话、任务、PID 或日志确认状态，不启动新任务。 |
| 用户取消                         | 立即停止，将结果标记为未完成，不自动恢复。                         |

只有代码、配置、输入或相关外部状态已经改变，原任务实际未启动，已确认的瞬时故障允许安全重试，或者已有结果无法恢复且用户明确批准重跑时，才能再次执行。重跑只覆盖当前证据缺口，并保留前次失败事实。
