# Vue 开发工作流

## 适用边界

本文件规定 Vue 页面、组件、指令、composable、store、单文件组件、动态 DOM 和 Vue 类型影响的专项要求。通用前端契约、状态、联调、响应式和可访问性由
`前端开发工作流.md` 负责。

## 单文件组件与类型契约

- 修改 Vue 单文件组件前，核对 template、script、style、组件导入、props、emits、slots、`v-model` 和暴露能力之间的关系。
- 修改 composable 或 store 时，核对状态生命周期、并发请求、缓存、清理、组件卸载和多实例共享行为。
- 修改公共组件、公共类型、全局声明、API 类型或类型配置时，分析直接和间接调用方、类型兼容性及受影响页面。
- 纯样式、静态资源或文档变更只有在实际内容、项目配置或公共契约表明存在类型影响时，才扩大类型分析范围。
- 不得通过 `any`、忽略指令、抑制规则或删除有效类型约束掩盖本次变更引入的问题。

## 动态 DOM 与 Teleport

只有任务涉及动态生成节点、Teleport、弹层样式或相关 inspection 时，才应用本节。

- 优先把局部样式锚定到模板中明确声明的类；运行时外层容器优先使用组件官方样式 API、CSS 变量或项目已有主题能力。
- Teleport 内容需要非 scoped 样式时，选择器仍应限制在当前组件明确拥有的类或项目认可的命名空间中。
- 不得只为消除 warning 改变 `teleported`、挂载位置、定位、触发方式、布局或业务逻辑，也不得直接抑制检查。
- 出现“选择器从未使用”时，先核对模板静态类、动态 `:class`、插槽内容、组件官方样式入口、运行时 DOM 和 inspection
  覆盖范围。证据表明确为误报时记录工具限制；否则修正模板类与选择器关系并复查。

## Vue 专项验证

从项目当前清单、锁文件和检查配置查明包管理器、Vue 工具链、支持文件类型和参数。不得安装依赖、猜测入口、切换工具链或伪造工具不原生支持的文件级参数。

对本次变更文件执行适用的模板、脚本、样式和格式检查。需要项目配置、跨文件依赖图或文件范围之外的上下文时，按 `非文件级执行与验证.md`
判断授权。

编辑后的格式化、IDEA inspection、文件级检查、修复闭环和影响自查按 `编辑格式化与文件级检查.md` 执行；非文件级类型检查、构建、测试和运行按
`非文件级执行与验证.md` 处理。
